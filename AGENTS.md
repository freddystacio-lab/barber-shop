# Reglas del proyecto

- La fuente de verdad comercial es `src/config/site.ts`; no incrustar datos del negocio en componentes.
- Mantener el sitio estático, accesible, mobile-first y sin servicios externos salvo aprobación explícita.
- La marca y el contenido son ficticios hasta que el propietario autorice datos reales.
- Ejecutar `npm run build` antes de entregar cambios.
